# Privacy Policy

## Overview

This extension is designed to help users search and discover products from images or videos and access AliExpress product links.

We are committed to protecting user privacy and ensuring transparency.

---

## Data We Collect

This extension may process the following data **only when the user actively uses the feature**:

* Screenshots of the current tab (captured via browser API when user triggers the feature)
* Image data extracted from the screen
* Product-related URLs or search queries

We do **not** collect:

* Personal identifiable information (name, email, password, etc.)
* Browsing history outside of the feature usage

---

## How We Use Data

Collected data is used strictly to:

* Analyze images and identify products
* Provide relevant product search results
* Generate affiliate links for AliExpress

---

## Data Sharing

We do **not sell user data**.

However, limited data may be shared with:

* AliExpress or related services to retrieve product results
* Third-party APIs (if applicable) to process image search

All data sharing is strictly required for the core functionality.

---

## User Control

* All data processing is **user-initiated**
* No data is collected in the background without user action
* The extension does not track users across websites

---

## Data Storage

* We do not permanently store personal user data
* Temporary data may be processed in memory and discarded after use

---

## Security

We take reasonable measures to protect data and ensure secure transmission.

We may update this policy from time to time. Updates will be reflected on this page.
