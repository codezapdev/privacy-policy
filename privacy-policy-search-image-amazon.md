# Privacy Policy

## Overview

This extension allows users to search for visually similar products from AliExpress based on images found on websites such as Amazon.

We are committed to protecting user privacy and ensuring transparency.

---

## Data We Process

This extension processes data **only when the user actively triggers the feature**:

* Images selected or captured from the current webpage (e.g., Amazon product images)
* Temporary image data used for search
* Product-related URLs (only for identifying the source context)

We do **not** collect:

* Personal identifiable information (name, email, passwords, etc.)
* Account data from Amazon, AliExpress, or any other website
* Browsing history outside of user-initiated actions

---

## How We Use Data

The data is used strictly to:

* Perform reverse image search
* Find similar products on AliExpress
* Display product results to the user

---

## Data Sharing

We do **not sell or monetize user data**.

However, limited data may be shared with:

* AliExpress or related services to retrieve product results
* Third-party image search APIs (if applicable)

All data sharing is strictly required for the core functionality of the extension.

---

## User Control

* All features are **explicitly triggered by the user**
* The extension does **not automatically collect or process data in the background**
* The extension does **not modify or interfere with Amazon or other websites**

---

## Data Storage

* No personal data is permanently stored
* Image data is processed temporarily and discarded after the search is completed

---

## Security

We take reasonable measures to ensure data is processed securely.
